Personal Reader Sync

This is an independently configured, personal Google Drive OAuth connection for synchronizing reading progress using Hoshi Reader.

After the owner authorizes access, Hoshi Reader can use the Google Drive API to store and retrieve its synchronization data in the owner's Google Drive. This web page itself has no sign-in feature, does not handle OAuth tokens, and does not access files.

This is a personal configuration page, not an official Hoshi Reader or Google service.
